## Comment les mettre en ligne (itch.io)
1. Sur itch.io : **Dashboard → ton jeu → Edit game**.
2. **Cover image** : bouton *Upload Cover Image* → `cover-630x500.png`.
3. **Screenshots** (colonne de droite) : *Add screenshots* → le GIF puis les 5 PNG, dans cet ordre.
4. Enregistrer (*Save*), puis vérifier la page publique.

Images fabriquées à partir du vrai jeu (captures Playwright du mode développement,
décor et obstacles posés à la main pour la mise en scène), GIF assemblé avec ffmpeg.
